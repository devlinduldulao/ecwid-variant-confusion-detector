# Marketplace Listing Copy

## App name

Variant Confusion Detector

## Short description

Merchant dashboard for finding confusing Ecwid variant structures before they create buyer friction.

## Long description

Variant Confusion Detector helps Ecwid merchants audit their catalog directly inside the admin dashboard. It scans product option trees, combination counts, stock fragmentation, duplicate labels, and unclear option naming to highlight which products need cleanup first.

The app is built for catalog-quality analysis, not shopper surveillance. It does not depend on a custom backend, visitor tracking, or a separate merchant database. Merchants can use the built-in preview mode to demo the dashboard with fake sample data, then switch to live Ecwid catalog data when the app is connected inside the real admin iframe.

## Value points

- Detect overloaded variant combinations before they hurt conversion
- Spot unclear option names, duplicate values, and fragmented stock coverage
- Prioritize the products that need cleanup first
- Demo the interface safely with preview mode before connecting live store data
- Runs as a static admin app without requiring a custom production server

## Scope note

This app analyzes Ecwid store profile and catalog data. It does not ingest shopper-session telemetry, online visitor behavior, or live storefront tracking events.
